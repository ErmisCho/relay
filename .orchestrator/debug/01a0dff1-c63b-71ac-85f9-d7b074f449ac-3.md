# Debug session: full-suite Windows portability failures
Created: 2026-09-27T00:00:00Z
Session: 01a0dff1-c63b-71ac-85f9-d7b074f449ac

## Phase 1 — Root Cause

### Error

`uv run pytest -q` completes with `13 failed, 503 passed, 22 skipped`.

### Reproduction

Windows 11, Python 3.13.5, local Postgres only. Full command took 193 seconds. No provider credentials or paid endpoints were used.

### Failure clusters and evidence

1. **Four file-artifact failures** (`demo/test_feed_and_reads.py`, `agent/test_research_e2e.py`). `Path(unquote(urlparse(url).path))` converts `file:///C:/...` into Windows path `\C:\...`; `urllib.request.url2pathname` correctly produces `C:\...`. The demo therefore cannot read a valid artifact and falls back to its summary/title.
2. **Three worker-kill failures**. `signal.SIGKILL` does not exist on Windows. `subprocess.Popen.kill()` is the standard cross-platform hard-stop API and has the required SIGKILL behavior on POSIX.
3. **Three code-run failures**. `commit_step` explicitly refuses every non-macOS host because `sandbox_argv()` returns `None`. The agent already loses its shell tool off macOS, but its file tools can produce a safe change. The worker's use of porcelain `git add` was the reason commit was sandbox-gated: repository-controlled clean filters and hooks can execute. Git plumbing (`hash-object --no-filters`, `update-index`, `write-tree`, `commit-tree`, `update-ref`) avoids those execution points and permits a safe cross-platform commit without adding a dependency or unsandboxed shell.
4. **Two shell-policy tests**. Production intentionally omits all shell tools off macOS, but fixed research instructions still name `run_command`, and one test unconditionally expects it. The secret-env execution test is macOS-only by design; instructions must describe optional shell use without naming an unavailable tool.
5. **One router status assertion**. A deliberately unreachable port can fail as connection timeout rather than connection-refused on Windows firewall policy. Both statuses correctly fail safe to `hard`; the exact transport subtype is environment-dependent.
6. **One symlink test**. Windows without Developer Mode/admin cannot create a test symlink (`WinError 1314`) before production code runs. This capability absence must skip that test; Unix and enabled Windows hosts continue exercising it.

### Suspect commits

- `85cb231` introduced cross-platform-sensitive artifact and process tests.
- `fbf796f` introduced macOS `sandbox-exec` as the only worker-side commit boundary.
- `a5aafb4` restored tests that assumed a POSIX host.

### Hypothesized root cause

The merged phase-1 implementation and test suite were developed against macOS/POSIX assumptions. Windows paths, signal constants, sandbox capabilities, firewall outcomes, and symlink privileges were not represented. · Confidence: high

## Phase 2 — Pattern

These are deterministic platform-boundary failures, not business-logic failures. The common repair is to use existing cross-platform stdlib/native APIs and keep security fail-closed:

- URL decoding via `url2pathname`;
- process termination via `Popen.kill`;
- git object plumbing that does not execute agent-controlled hooks/filters;
- capability-aware instructions/tests;
- skip only when the OS cannot construct the symlink fixture.

## Phase 3 — Impact

Affected production paths:

- browser artifact rendering on Windows;
- durable crash/replay tests on Windows;
- all code commitments on Windows;
- local research prompts when no sandbox shell exists.

Affected test-only assumptions: URL conversion in e2e assertions, router transport subtype, and symlink fixture creation.

## Phase 4 — Solution

Apply the minimal cross-platform replacements above. Add a regression test proving an agent-controlled clean filter is not executed during commit. Verify each failed cluster, then the complete pytest/mypy/Ruff gates.

## Resolution

Applied all six portability repairs. Code commits now use no-filter Git plumbing and a regression proves an agent-controlled failing clean filter is never executed. Targeted clusters passed; final full suite: 524 passed, 25 capability/opt-in skips. Mypy and Ruff are clean.
