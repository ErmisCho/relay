# Debug session: context timeout cancels affirmative assent classification
Created: 2026-09-27T00:27:00Z
Session: 01a0dff1-c63b-71ac-85f9-d7b074f449ac

## Phase 1 — Root Cause

### Error

Full suite: `1 failed, 523 passed, 25 skipped`. The failing resend/grace test expected an affirmative classification to preserve a reserved dispatch, but the reservation became cancelled.

```text
hook CommitmentHook before_model timed out after 0.50s
assert res.status == "reserved"
actual: "cancelled"
```

### Reproduction

```text
uv run pytest -q tests/delegator/commitment/test_resend.py \
  -k request_near_the_deadline_holds_the_commit_while_classifying
```

The test deliberately delays assent classification 1.2 seconds to cross the original grace deadline.

### Hypothesized root cause

The newly integrated generic 0.5-second context-I/O budget treated every `before_model` hook as optional. `CommitmentHook` and `ScopeHook` are safety gates, not optional context: cancelling assent classification changes dispatch semantics, and cancelling scope classification can bypass refusal behavior. · Confidence: high

## Phase 2 — Pattern

Latency protection may skip persistence, reports and summaries, but must never simplify away safety checks. The correct boundary is explicit: safety-critical hooks complete; optional context hooks are bounded.

## Phase 3 — Impact

Affected: delayed assent/resend handling and potentially delayed scope checks. Risk: incorrect dispatch cancellation or unsafe model response. Reports/idea context can still be dropped after the budget without blocking speech.

## Phase 4 — Solution

Mark `CommitmentHook` and `ScopeHook` as safety-critical and exempt only those hooks from the optional context timeout while preserving exception logging. Keep the timeout for every other hook and the persistence boundary. Rerun the focused race test, stalled-context regressions and full suite.

## Resolution

Marked commitment and scope hooks safety-critical; optional hook/persistence I/O remains bounded. Scope refusal persistence has its own timeout so the refusal note still returns if storage stalls. The focused race pair passed (2/2), scope/context regressions passed (88 passed, 1 opt-in skip), and the final suite passed 524 tests.
